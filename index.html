How to build

1. Create your app configuration here. 2. Push the project to GitHub. 3. Open Actions in this repository. 4. Run “Build Android APK and AAB”. 5. Enter the website URL and version. 6. Download the workflow artifacts.

Important

GitHub Pages can host this interface, but browser JavaScript cannot securely start arbitrary GitHub Actions jobs without a server-side GitHub App/token. Never put a GitHub token in index.html. The repository workflow is the trusted build layer.
