How it works

Build APK sends the website URL and version to a Supabase Edge Function. The function uses a server-side GitHub token to dispatch the workflow. When GitHub finishes, the backend extracts the APK from the Actions artifact and returns it as a direct download.

Important: GITHUB_TOKEN must be stored as a Supabase secret. Never put it in this HTML file.
