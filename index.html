How it works

The website sends your app configuration to a protected Supabase Edge Function. The function dispatches GitHub Actions, which compiles the native Kotlin Android project and uploads the APK/AAB artifacts.

Security: the GitHub token stays server-side in Supabase and is never placed in this page.
