Web-to-Native Android

Website → APK

Turn an HTTPS website into a real Android APK/AAB using a native WebView wrapper.

Only HTTPS websites are accepted. GitHub Actions performs the actual APK/AAB compilation.

1Enter your public HTTPS website.
2Open the Android build workflow in GitHub.
3Set website_url to your website and run the workflow.
4Download the APK or AAB artifact.
